# Introduction Designer update (unreleased)

- New: **Simple mode** (default) with an **Advanced** switch. Simple hides free placement, HTML import, layered borders, per-item CSS and other expert controls; nothing is deleted from the design.
- New: **Pick a look**, 8 ready-made styles. Your text stays and Ctrl+Z undoes the change.
- New designs start in the **Stack** layout. Plain labels (Card width, Space inside the card, Rounded corners).
- Preview is JuicyChat's own width, 748 px (480 px and 360 px phone sizes stay available).
- Character meter: amber near 12,000, red over JuicyChat's 15,000 limit, and a reminder that the code counts, not only the words.
- A note appears when JuicyChat's rules remove some pasted CSS or HTML.
- 3-step tip strip on the first visit (the ? button brings it back).
- The designer files are now shared with Juicy Blueprint Studio and the web page; see `docs/introduction-designer/` for the single-file web page.

# Juicy Chat Creator Tools v1.1.0

This repaired source keeps the app's existing version number.

- WebP Maker now supports one MP4/WebM for animated conversion and 2+ videos for merging.
- Introduction Designer now fits the canvas to the actual content height, offers a Fit content button, and uses simplified labels.
- Older saved canvases that were stuck at a manual height are reset once.
- Image crop, Undo/Redo, HTML editing, inline styles and existing updater are preserved.

Desktop executables must be rebuilt on the relevant platform.
