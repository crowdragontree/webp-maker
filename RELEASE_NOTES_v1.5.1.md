# JuicyChat Creator Tool v1.5.1

## New
- **Analytics tab.** If the JuicyChat Analytics Tool is installed on your computer, an **Analytics** tab shows up next to Settings with Dashboard, Your Performance, JuicyChat Analysis, Engine Library and Settings. It runs the installed Analytics Tool's own code, so when the Analytics Tool updates, the tab updates with it.
- **JuicyChat sign-in in Settings.** With the Analytics Tool installed, **Settings** has a magic-link sign-in for the Analytics tab.
- **Separate from the Analytics Tool.** The Creator Tool keeps its own sign-in and its own data. The two apps never pull from JuicyChat at the same time: one waits until the other is done.
- Without the Analytics Tool, none of this shows.

## Unchanged
- Everything else works as in v1.5.0.

## Compatibility
- Windows 64-bit and Linux 64-bit

## Updating
**Check for updates → Update & Restart** installs this version.
