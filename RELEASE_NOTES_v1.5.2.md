# JuicyChat Creator Tool v1.5.2

## New
- **Import your Introduction HTML styles.** The Introduction style box in the Bot Builder has a new **Import HTML files…** button. Pick as many `.html` files as you like at once and each one becomes a saved style, named after its file (`Stepsister_Series.html` becomes "Stepsister Series"). A style named for a series is picked automatically for that series. When two files belong to one series (for example Female and Futa), you pick between them.

## Bug Fixes
- **Your Introduction styles are no longer lost.** They were kept only in the window's own storage, which can come back empty. They are now also saved in a file in the app's data folder (with one backup copy of it before each save) and come back by themselves if the window's storage is ever empty.

## Unchanged
- Everything else works as in v1.5.1.

## Compatibility
- Windows 64-bit and Linux 64-bit

## Updating
**Check for updates → Update & Restart** installs this version.
