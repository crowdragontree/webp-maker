# JuicyChat Creator Tool v1.5.0

## New
- **Search.** A **Search** button in the top right opens a search pop-up that searches the tool as you type: the text on every tab, including tabs that are not open, and what is written in the text boxes (the Bot Builder's sections and your settings; password and key fields are never searched). The Introduction Editor is a separate page and is not searched. Several words find the places that have all of them. Each result shows where it is, with the words highlighted. A tag is searched in quotation marks: `"slice of life"` finds that tag, and `"slice` finds every tag that starts with it. Clicking a result goes to exactly that place, with the words highlighted.
- **Spelling and grammar colours.** In the Bot Builder's Greeting and Introduction, spelling mistakes are marked in red, grammar in blue and wording in purple, right in the text box, with a small key above it.

## Changed
- **Checks.** Clicking a check in the Checks list now goes to its section with the problem marked: red for a thing to fix, yellow for a note (the words the check quotes, or the punctuation it names). A check that names nothing in particular outlines the whole section in its colour. Each check has a **Copy** button next to **Go to section**, and clicking a check no longer copies it.

## Unchanged
- Everything else works as in v1.4.7.

## Compatibility
- Windows 64-bit and Linux 64-bit

## Updating
**Check for updates → Update & Restart** installs this version.
