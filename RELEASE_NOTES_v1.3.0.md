# JuicyChat Creator Tool v1.3.0

## New
- **Bot Builder tab.** Write a whole bot in the Creator Tool: Scene Name, Name, Age, Introduction, Personality, Scenario, Greeting, Tags and Interaction Examples, with live character counts, the format checks, spelling, saved bots and your own templates (+ Add, Replace, Restore, Remove). It is the Blueprint Studio's Bot Builder without anything AI-related, without the Draft-from tab and without Auto-complete.
- **Introduction Editor ↔ Bot Builder.** Press **Design in Introduction Editor** in the Bot Builder's Introduction. The editor opens with the bot's words already in it, and **Save and Return to Bot Builder** puts the finished Introduction back into the bot.
- **PNG Compressor tab.** Shrinks pictures one at a time and saves each next to the original as `<name>_compressed.png`. The original is never touched.
- **Every picture format.** WebP Maker, the PNG Compressor and the Bot Builder pictures accept PNG, JPEG, WebP, GIF, BMP, TIFF, AVIF, ICO, SVG and HEIC/HEIF. Animated GIFs use their first frame.
- **Settings tab with the Grammar Engine (LanguageTool).** Install it, or remove it, from Settings. Once installed the Bot Builder checks grammar as well as spelling. It is optional; the Bot Builder works without it.
- **Export the bot as `.json`** next to Copy and Save as .txt.
- **Interaction Examples** (optional). Conversations (User / Character) and Triggered Interactions (Trigger / Response), each 0 / 5,000 characters, with **+ Add Example**.
- **Past / present tense** for the Greeting and the Introduction, with **Undo** and **Restore original** (goes back to the text as it was before the first tense change, however many times you switched).
- **you / your ↔ {{user}}** switch for the Greeting.

## Changes
- **Any template style works.** Bots written as `Sophie: -dialogue-` (or any other way of writing speech and narration) are no longer flagged for not using "dialogue" *narration*. The checks follow the style the template itself uses.
- **Introduction limit is 15,000 characters** in the Bot Builder.
- **The Greeting has no picture upload** in the Creator Tool. Pictures are plain picture markers only, because the platforms' own uploads are not reachable from here.
- Ships with one **Blank bot** template. Add your own templates with **+ Add**.

## Unchanged
- WebP Maker and the Introduction Editor work as in v1.2.2. Saved designs and templates keep working.
- Everything stays on your computer. No uploads.

## Compatibility
- Windows 64-bit and Linux 64-bit

**Check for updates → Update & Restart** installs this version.
